I created this concept for my TCI exam. Currently, it is still a Minimum Viable Product (MVP) engine. More features and core mechanics will be added to this concept soon!



Future Roadmap (To be implemented one by one)



\* Various Note Types: Support for various note values (1/2, 1/4, 1/8, triplets, etc.) to match real music score sheets.

\* Sheet Music Aesthetic: A complete sheet book visual style, including song titles, BPM displays, and time signatures.

\* Visual Cues: Dynamic background color flashes for every incoming note to help with timing.

\* Beatmap Creator: Automated beatmap generation via `.mid` (MIDI) file uploads! (Yay!)

\* Game Mods: Gameplay modifiers such as Hidden notes, Sudden, No-Line mode, etc.
